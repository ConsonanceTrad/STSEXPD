# 早期融合原型记录（非 SPS-SPD 完整性说明）

> 本文从旧 `MPD` 工程保留，仅记录 SPS-SPD 当前基线继承的早期融合功能。
> 它不是特别惊喜像素地牢 0.9.8 的完整内容清单，也不能作为复刻完成证明。

本项目以破碎像素地牢4.0为基底，保留主线26层、装备成长、天赋、炼金、存档和战斗模型；特别惊喜像素地牢的正常可游玩内容则按破碎4.0接口重新实现。两套旧引擎不能直接混装，因此本版保留原内容的用途、路线和主题，不照搬会破坏存档或平衡的旧全局代码。

桌面版使用独立的“融合像素地牢”存档目录；安卓版 application id 为 `com.hmdzl.spsexpd`，可以与官方破碎像素地牢并存。官方更新与新闻入口不参与本版运行：上游的 `githubUpdates` / `shatteredNews` 联网实现已归档到 `_ref/archive/upstream-network-services/`，仓库内只保留 `pd/services/{news,updates}` 的调试实现。

## 本版内容总览

- 33条额外可选路线：8张挑战地图和25处异界目的地。
- 11个可选职业：破碎4.0原有6职业、魔剑士，以及演员、星兵、信徒、苦修者。
- 8套职业外观和8种独立战斗风格；外观不再暗中改变数值。
- 16种伙伴，包含护卫、突击、远射、支援四种定位。
- 11件融合近战武器、2件护甲、2根法杖、2枚戒指、2件神器、2种投掷武器和4种消耗品。
- 多利亚镇有限商店、新居一次性锻造、四波首领连续战和Zot终局链。
- 全部新增状态均写入存档，并提供旧存档默认值。
- 魔剑士、演员、星兵、信徒和苦修者现已拥有独立动画图集与选角原画，不再复用法师、盗贼、决斗家或牧师的视觉素材。

## 露珠袋能力

水袋保留破碎4.0原有的按缺失生命消耗露珠治疗，以及装满20滴后祝福重生十字架的用途；同时按特别惊喜露珠瓶的功能重新实现四项辅助能力：2滴露珠照明50回合、3滴露珠侦测本层生物5回合、5滴露珠清除普通有害效果并提供2回合净化保护、4滴露珠加速5回合。每次使用消耗1回合。

水袋放入快捷栏后，点击或按对应数字键会先打开功能选择面板，不会直接饮用。快捷栏已扩展为9格，桌面端默认使用数字键1至9；宽屏直接显示最多9格，窄屏开启快捷栏切换器后按每页3格循环显示三页。旧存档原有的前6格保持原位置。

特别惊喜原版的种植、提纯、随机强化、溢出容量、加速浮空等能力暂不加入。它们在破碎4.0的资源体系中会批量制造植物或烹饪资源、替代升级卷轴，或明显削弱陷阱和地形机制，不适合作为20滴容量水袋的常驻能力。

## 职业、外观与战斗风格

演员可转职为巨星或戏法师；星兵可转职为特工或领袖；信徒可转职为工匠或牧者；苦修者可转职为戒律者或黑客。每个新职业都有独立初始配置、五阶职业天赋、两个专精和三种可用终阶能力，数值预算以破碎原职业为基准。

新增职业复用破碎天赋机制时，界面会按当前职业和专精调整称谓。若某项天赋对原职业与其他职业具有不同效果，融合职业只显示自己实际生效的兼容效果，不再混入法师、盗贼、女猎手、决斗家、战士或牧师的专属说明。

特别惊喜中实际可选的8套皮肤图集已经接入开局界面、游戏内英雄、存档预览、存档列表和排行榜。旧版皮肤中夹带的战斗数值被拆分为平衡、猛攻、守御、灵动、专注、坚韧、战术、冒险8种战斗风格；每种风格都同时具有优势和代价，旧存档默认使用原外观与平衡风格。

魔剑士采用独立的持剑角色与护甲阶段动画；演员使用礼帽和手杖主题；星兵使用机械战士主题；信徒使用星空修士主题；苦修者使用忍者武者主题。五张800×450原画均与对应256×128动画图集配套，来源与许可记录在素材来源文档中。

## 伙伴、城镇与首领

完成春节庭院后获得伙伴图鉴。16种伙伴按四种定位共享封顶成长，可选择、召唤、召回和喂食；喂食会消耗正常食物。伙伴不产生物品或经验，同一楼层阵亡后只能重新召唤一次，选择与召唤限制均保存。

多利亚镇每局仅出售治疗药剂、食物、地图卷轴和鉴定卷轴各一件，售出后不补货；信徒购买价九折。新居可花费金币把一件尚未强化的融合近战武器提升至+1，每局只能锻造一次。库存和锻造状态跟随支线楼层存档。

远征首领具有路线独立名称、近战或远程模式、异常攻击、两段式护盾、有限召唤与阶段传送。首领连续战依次对抗黏液霸主回响、隐匿天狗回响、矮人国王回响和暗影之神回响；只有第四波结束才完成路线，当前波次会保存。

## 装备与数值边界

融合近战武器包括仪式剑、牧笛、森之守御、战鼓、战斗竖琴、三角铁、战斗长笛、战争号角、双节棍、转经轮和风瓶。随机牌组中融合近战武器权重为1、普通同阶武器通常为2；涌流法杖、血契法杖、魔力之戒、知识之戒、火箭弹和风暴回旋镖也以低权重加入牌组。斯卡蒂之眼、努姆林王冠、生命护甲与猫鲨护甲只作为一次性支线奖励，不进入可反复随机获取的神器池。

所有新增装备沿用破碎4.0的强化、力量需求、诅咒和掉落规则。带控制、溅射、回复、加速或额外射程的装备会降低基础伤害、防御上限或出现权重；普通支线奖励不超过当前章节一件未强化装备或两件普通消耗品的预算。终局难度依靠机制和组合增加，不使用无限生命、无限伤害或巨量初始物资。

## 存档与质量检查

挑战解锁、异界解锁、首次奖励、返回坐标、职业皮肤、战斗风格、伙伴选择、每层召唤限制、城镇库存、锻造状态、谜题状态和首领波次均会保存。旧存档缺少新字段时采用安全默认值，并自动补发两本日志；已经完成春节庭院的旧融合存档会补发伙伴图鉴。

发布检查会验证中英文融合资源键一致、资源键不重复、文本为UTF-8且无常见乱码标记、固定地图行宽、33条路线、29份一次性奖励、8套战斗风格、8张职业皮肤图集尺寸、外观返回路径、水袋能力消耗以及关键存档字段。桌面完整构建和启动测试通过后，本版本才视为可交付。

## 不纳入成品的旧内容

开发者生成器、测试敌人、测试法杖、测试斗篷、作弊开关、无法从正常流程抵达的废弃楼层、无上限强化、耐久损毁和巨量初始资源不迁入。原主线下水道、监狱、洞窟、城市、恶魔大厅及其首领由破碎4.0对应内容取代，不作为重复支线再次加入。
